# Foliage mesh overrides (optional)

Runtime builds simple tree/grass prototypes when these assets are missing.

To use free marketplace / Plant packs, import StaticMeshes here named:

| File | Species id (bake) |
|------|-------------------|
| `SM_Oak` | oak |
| `SM_Cedar` | cedar |
| `SM_Scrub` | scrub |
| `SM_Lawn` | lawn |
| `SM_Beach` | beach |
| `SM_Marsh` | marsh |

Paths resolved as `/Game/Foliage/SM_Oak` etc.

Pivot should be at the ground center. Units: UE cm. Scale ~1 = full-size tree (~3–6 m crown for oaks).
